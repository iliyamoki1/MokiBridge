# Moki Bridge — پوستر داخل ایران (رله اضطراری قطع ملی)

## مسئله
سرور اصلی پل تو آلمانه. تو قطع ملی، ایران ترانزیت بین‌الملل رو می‌بنده؛
سرور آلمان دیگه به API بله (tapi.bale.ai) نمی‌رسه — ولی خود بله داخل
ایران کار می‌کنه. پس پست‌کردن باید از داخل شبکه ملی انجام بشه.

## راه‌حل — سه لایه
1. **صف خروجی آلمان هیچ‌وقت چیزی رو رها نمی‌کنه** — با بک‌آف تا ابد
   تلاش می‌کنه؛ به محض برگشت لینک، همه‌چیز به ترتیب پست می‌شه.
2. **انبار (stockpile)** — هر کانفیگی که موفق پست می‌شه، یه نسخه‌ش تو
   `stockpile.jsonl` + `stockpile_files/` روی سرور آلمان ذخیره می‌شه
   (۴۰۰ تای آخر). تا وقتی لینک بالا هست، این انبار با پوستر همگام می‌شه.
3. **پوستر داخل ایران** (`poster.py` — فقط پایتون خالی، بدون نصب هیچی) —
   روی هر هاستی داخل ایران اجرا می‌شه و تو کل مدت قطعی، انبار رو با
   فاصله (پیش‌فرض هر ۵ دقیقه یه پست) تو چنل می‌ریزه. تکراری هم نمی‌فرسته
   (ردیابی با هش تو `posted.txt`).

## اجرا روی هاست ایران
```bash
BALE_TOKEN=<توکن بات> BALE_CHAT_ID=<آیدی چنل> python3 poster.py
# تست بدون ارسال واقعی:
DRY_RUN=1 BALE_TOKEN=x BALE_CHAT_ID=y python3 poster.py
```

## همگام‌سازی انبار (وقتی لینک بین‌الملل بالا هست)
```bash
rsync -az server:/opt/bale-bridge/stockpile.jsonl \
          server:/opt/bale-bridge/stockpile_files/ ./ 
```
(مسیرها رو با هاست پوستر تنظیم کن.)

## گزینه‌های هاست داخل ایران (نیاز به ثبت‌نام خود ایلیا با موبایل ایران)
- **لیارا (liara.ir)** — PaaS ایرانی، پلن رایگان/ارزان کانتینر؛ مناسب همین فایل تک‌فایلی.
- **چابوکان (chabokan.net)** — هاست ابری ایرانی با پلن‌های سبک.
- **ابر آروان (arvancloud.ir)** — PaaS ایرانی.
- هر VPS ایرانی ارزون هم کار می‌کنه — پوستر فقط خروجی به tapi.bale.ai می‌خواد.
